# YaKyoLife - 日本棒球人生模擬器 ⚾

這是一款從既有棒球人生模擬器分支改編的日本棒球生涯養成遊戲。玩家從日本高中出發，可能走向大學、社會人棒球、獨立聯盟或日本職棒選秀，之後再挑戰 NPB 一軍與 MLB；CPBL 則保留為海外職業市場與第二次機會。

重整頁面不會保存進度。同一種子、同一選擇可以重播同一段人生。

## 主要生涯路線

- **日本高中 → 大學／日職選秀／社會人／獨立聯盟**
- **NPB育成 → NPB二軍 → NPB一軍**
- **NPB → MLB**：日本職棒球員的主要旅外夢想路線
- **CPBL海外市場**：可由日本職棒、社會人、獨立聯盟等職業生涯階段取得機會，分為一軍洋將與二軍／培養型路線
- **MLB／小聯盟**：保留旅美養成與逐級升級體系

## 改編原則

本專案刻意保留原作成熟的核心系統，包括種子 RNG、20–80 能力養成、傷病、合約、升降級、生涯時間軸、國際賽、隱藏特質、結算與本地儲存；主要改造的是棒球世界觀、聯盟層級、球隊資料與日本職棒生涯流程。

CPBL 不再作為日本主線的起點，而是獨立的海外市場；日本職棒則使用 NPB育成、NPB二軍、NPB一軍三層職業體系。
