# YaKyoLife - 日本棒球人生模擬器

從日本高校出發的棒球生涯模擬器。甲子園、大學、社會人、獨立聯盟、日職十二球團、旅美與日本代表；中職是海外洋將市場，不是這段人生的起點。

線上：[chumbuds9139.github.io/yakyulife](https://chumbuds9139.github.io/yakyulife/)

重整頁面不會保存進度。同一種子、同一選擇可以重播同一段人生。詳細規則見 [YaKyoLife-WIKI.md](YaKyoLife-WIKI.md)。

## 生涯路線

- **高校**：高三可升學、直接投入日職選秀（一生一次），或加入社會人／獨立聯盟（不消耗選秀資格）
- **大學**：大二起可投選秀；畢業後還沒投過也能投這一次
- **社會人／獨立聯盟**：季末可選秀、等十二球團合約，或接中職洋將約；不是日職農場
- **日職**：育成 → 二軍 → 一軍；日職二軍能力夠時也可能接到中職洋將約
- **旅美**：小聯盟逐級挑戰 MLB
- **日本代表**：經典賽、12 強為自願邀請，不是徵召
